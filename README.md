"The World — 27 November 2026": a newspaper front page summing up Friday 27 November 2026 in one image — US Thanksgiving storms, New Zealand's final election count, Ebola in Congo, Nepal's landslide dead, and Belgium's new satellite factory.

Run it with `python3 main.py` — it copies `image.jpg` to `$MAKEFUN_OUTPUT_DIR/entry.png`.
