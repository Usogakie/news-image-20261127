A Python program that draws a one-page newspaper front page summing up the world's news of Friday 27 November 2026: the postponed Macy's 100th Thanksgiving Day Parade, New Zealand's deadlocked final election count, the Ebola outbreak in eastern Congo, the US disabling a blockade-runner in the Gulf of Oman, Spain's eve-of-election polls, and Europe's new satellite megafactory — plus an "In Brief" strip. It writes a deterministic 1024x1024 PNG to `entry.png` using only Pillow and the DejaVu fonts already on the system, with no network access.

## Run it

```sh
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.png` is written (default `/output`).
